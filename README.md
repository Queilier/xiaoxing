# 小星科学探索

## 添加主题视频

将 MP4 视频放入 `public/videos/`，使用以下文件名，网页播放器会按当前科学主题自动切换：

- `遇水开花.MP4`
- `牙签五角星.mov`

启动项目后，选择主题即可在左侧播放视频。视频播完后，右侧聊天会自动进入提问环节。手机和平板上视频区会显示在聊天区上方。

## 本地启动

```bash
npm install
npm start
```

然后打开 http://localhost:3000 。聊天和语音服务还需要在 `.env` 中配置 Coze 环境变量，具体部署方式见 [DEPLOY.md](DEPLOY.md)。
