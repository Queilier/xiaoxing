# 小星科学探索

## 热身与正式活动

网站入口 `/` 是独立热身页：主试先示范提问，再让儿童自由聊天、练习按住说话、文字发送和语音重播。点击底部“正式开始”进入 `/activity` 的科学视频与正式实验流程。

热身对话存储在独立的会话记录中，不作为正式问答上下文。通过热身进入正式活动时会新建正式会话，浏览器中已有的正式记录会先以带时间戳的独立键备份，避免覆盖。

## 下载实验数据

从热身页点击“正式开始”后，热身记录会保存到当前正式会话。填写被试编号后，正式页的“下载数据”导出同一份 JSON：原有正式实验字段保留在顶层，`warmup` 包含热身聊天（区分主试/儿童）、起止时间、操作事件和错误。两部分关联同一被试编号，但 AI 对话上下文独立。刷新正式页会保留已关联的热身；更换被试不会将上一个孩子的热身带入新会话。直接进入正式页而没有热身记录时，`warmup` 为 `null`。导出的是文字及操作数据，不包含原始录音。

## 添加主题视频

将 MP4 视频放入 `public/videos/`，使用以下文件名，网页播放器会按当前科学主题自动切换：

- `遇水开花.MP4`
- `牙签五角星.mov`

启动项目后，选择主题即可在左侧播放视频。视频播完后，右侧聊天会自动进入提问环节。手机和平板上视频区会显示在聊天区上方。

## 本地启动

```bash
npm install
npm start
```

然后打开 http://localhost:3000 。聊天和识别需要在 `.env` 中配置 `OPENAI_API_KEY`，并确保 OpenAI API 账户有可用额度。配音现支持豆包的“邻家女孩 2.0”：设置 `TTS_PROVIDER=doubao` 并填写 `DOUBAO_API_KEY`，示例见 `.env.example`。具体部署方式见 [DEPLOY.md](DEPLOY.md)。

macOS 本地服务会自动使用系统设置中的 HTTPS 代理。也可以通过 `OPENAI_PROXY_URL` 手动指定代理地址，或设为 `direct` 禁用代理；Render 等云端默认直连。修改网络设置后需要重启服务。
